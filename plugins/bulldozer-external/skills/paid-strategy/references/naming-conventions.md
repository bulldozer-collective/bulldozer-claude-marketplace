# Campaign Naming Convention

Reference for the "Naming Conventions" section of `paid-strategy`. Apply this structure to every
campaign created across platforms — consistent naming is what makes cross-platform reporting
(blended CAC, the attribution work described in the main skill) possible without manual relabeling.

```
[Platform]_[Objective]_[Audience]_[Offer]_[Date]

Examples:
GOOG_Search_Brand_Demo_2026Q3
META_Sales_ProspectingBroad_FreeTrial_2026Q3
LI_LeadGen_CMOs-SaaS_Whitepaper_Sep26
```

Keep each segment short and stable across the account's lifetime — the goal is that anyone
filtering a reporting export by platform, objective, audience or offer can do it with a plain
text match, without needing a lookup table to decode the name.
