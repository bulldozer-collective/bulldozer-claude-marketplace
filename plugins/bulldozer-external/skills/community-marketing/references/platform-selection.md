# Platform comparison — full table

Each row is what to weigh before recommending a platform in the output. The decision rule in
the main skill file picks a winner from this table based on audience type; use this table to
justify the choice and to flag the drawback the client should accept going in.

| Platform | Best for | Key drawback |
|----------|----------|-------------|
| **Discord** | Developer, creator, gaming communities; real-time | High noise, onboarding friction, hard to search |
| **Slack** | B2B/professional communities; familiar to SaaS buyers | Free tier hides messages and files from search after 90 days, and — since August 2024, per Slack's own help docs — permanently deletes anything older than a year; a Slack community on the Free plan cannot build durable, searchable collective memory the way a Discourse forum can, so flag this before recommending Slack Free to a client who wants a long-term knowledge base, not just a chat room |
| **Circle** | Creator/course communities; clean UX, strong customization and automation | Less organic discovery; requires driving traffic yourself |
| **Skool** | Community bundled with a course/curriculum and gamified engagement (points, levels, leaderboard) — increasingly used for B2B founder and practitioner communities, not just creator courses | Weaker fit if you don't have a course or structured curriculum angle; less enterprise SSO/compliance tooling than Slack |
| **Discourse** | Long-form technical communities; SEO value | Slower velocity; higher effort to post |
| **Reddit** | High-volume public communities | You don't own it; moderation is hard |
