# Benchmarks

| Metric | Target | Investigate |
|--------|--------|-------------|
| Connection accept rate | 30–45% (2026 vendor average sits at 27–30%; 60%+ is top tier) | <20–25% → request note reads like a pitch |
| First DM reply rate | >15% (2026 average across a 13M-request dataset: ~10.4%) | <8% → signal too weak or message too long |
| Positive reply rate | 10–18% of replies | <5% → message reads like a pitch |
| Meetings per 100 sequenced | 3–6 | <2 → ICP fit or signal quality issue |
| Touch 5 reply rate | 8–12% (roughly consistent with 2026 vendor data on post-engagement breakup replies, 10–15%) | <3% → breakup tone is too aggressive |

The two rows with a cited 2026 figure (accept rate, first DM reply rate) come from the same large vendor dataset (13.2M requests) cited since the original check — rechecked 2026-09-14, unchanged. The other three rows are inherited order-of-magnitude estimates: a rechecked search on 2026-09-14 still turned up wildly inconsistent vendor numbers for "meetings per 100" — one newer source cites 1–2 booked per 100 *connected* prospects at median (up to 4–5 in the top quartile at scale), a different denominator than "per 100 sequenced" and still not reconcilable with the other figures found — so none of those three rows is precise enough to cite as-is. Use them as a rough bar, not a guarantee.

If accept rate is below 20–25%: the connection request note reads like a pitch. Rewrite it with less specificity about your offer and more specificity about the signal.

If reply rate is above 5% but positive reply rate is below 30%: the message is creating curiosity but not relevance. The signal and the offer aren't clearly connected.
