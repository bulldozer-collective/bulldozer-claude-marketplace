# The sequential ("always-valid") testing exception to the peeking rule

The one legitimate exception to pre-committing to a sample size and trusting it is a test tool built on sequential ("always-valid") testing rather than a fixed-horizon p-value — it can be monitored continuously without inflating false positives, by design. It's a property of the underlying statistical method, not a setting to turn on in an ordinary calculator: don't assume a tool has it unless its own methodology documentation says so. It also trades some statistical power for that safety, and gets less reliable when traffic between variants is heavily imbalanced.

If the test tool doesn't document this method, treat every early read as informational only and apply the fixed-sample rule instead. Evan Miller's site — already linked in the main text for fixed-horizon sample sizing and for the SRM chi-squared check — also has a separate [Sequential Sampling Calculator](https://www.evanmiller.org/ab-testing/sequential.html) built for this exact method; use it, or the platform's own documented sequential mode, rather than reading a fixed-horizon p-value early and assuming the always-valid guarantee applies by default.
