# Team Selling and Partner-Sourced Deals: HubSpot Credit Levels

**Two different levels here — don't conflate them.** HubSpot the product does have a native credit-sharing mechanism, Deal Splits (`crm.objects.dealSplits`, gated to Sales Hub Enterprise): it lets several users share a percentage of one deal's amount, writes `Split Owner` / `Split Amount` / `Split Percentage` onto the deal, splits across 3+ reps as long as the percentages sum to 100, and rolls each split owner's share into *their own* sales goal once the deal closes won — a real split, not just `hubspot_team_id` (the owning team, never a credit split) and distinct from a plain deal collaborator (added to the deal, no share of the credited amount). But Bulldozer OS's HubSpot connector doesn't expose this object today — a live schema call (`discover_hubspot_schema`) returns no `DEAL_SPLIT` type among what the connector can read or write, and a property search on a live portal turns up no split field at all, only `hubspot_owner_id` (whose own native description says to assign extra users via a custom property) and whatever workaround a given portal has already built. So the right move for a Bulldozer project isn't "HubSpot can't split credit" — it's: first confirm directly in the client's own HubSpot admin whether Deal Splits is turned on for their portal (Bulldozer OS can't read or activate it); if it is, use it; if it isn't, build a custom property of **type User** — not a text field or a generic picklist — so it still supports per-person filtering, reporting, and permissions the way a native owner field would. One Bulldozer portal has already built exactly this pattern as its workaround.
