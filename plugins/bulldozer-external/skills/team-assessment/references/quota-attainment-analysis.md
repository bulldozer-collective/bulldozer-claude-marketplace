# Quota Attainment Analysis — Format, Patterns and Pipeline Coverage

## Attainment analysis format and pattern identification

**Attainment analysis format:**

| Rep | Quota | Attained | % | Tenure | Ramp complete? | Pipeline coverage (last quarter) |
|-----|-------|---------|---|--------|---------------|-------------------------------|
| | | | | | | |

**Pattern identification:**

| Pattern | Diagnosis | Action |
|---------|-----------|--------|
| All reps below 60% | Quota too high or pipeline insufficient | Review quota-setting method + pipeline coverage ratio |
| Some reps at 100%+, others at <30% | Performance distribution issue | Coach bottom performers; understand what top performers do differently |
| New reps underperforming | Ramp too long or onboarding insufficient | Audit ramp program; check if new reps have pipeline to work |
| Tenured reps declining | Motivation, territory, or product-market concern | 1:1 investigation; check if territory has changed |

## Pipeline coverage check

**Pipeline coverage check:**
- Pipeline coverage ratio = total open pipeline ÷ quarter revenue target
- The right target is a function of win rate, not a flat number: coverage ≈ 1 ÷ win rate. A 25% win rate on qualified deals needs roughly 4x coverage; a 20% win rate needs roughly 5x.
- 2026 shift to note: the old 3–4x rule of thumb assumed cold-sourced pipeline closing near 30%+. With cold-sourced win rates now commonly cited at 15–22% (vs. 40–60% for warm/referred pipeline), most B2B teams need 4–6x coverage — higher still for enterprise motions (12–15% win rate → 6x+). Treat these win-rate bands as a directional convergence across secondary sources, not an audited figure attached to a named study: the GTM benchmark report most often invoked behind them (Ebsta × Pavilion, "2025 GTM Benchmarks" — 655,000 opportunities across 349–387 companies, not the ~4.2M/~530 some 2026 blog posts repeat) does not, on a direct read, contain any breakdown of win rate by pipeline source — its actual findings are about overall win-rate trend, rep concentration, and deal-cycle slippage. If a client pushes back on the range, say it's a market direction several sources agree on, not a named study's finding. Compute the target from the team's own win rate rather than defaulting to 3–4x.
- If coverage is below the team's own win-rate-implied target: the problem is top-of-funnel volume, not rep skill
- If coverage is at or above that target but attainment is still low: the problem is deal quality or pipeline source mix (cold vs. warm), not volume
