# Visual System Checks

## Step 5 — Running the logo swap test twice

**Run it twice — it tests two different things.** Removing only the logo/wordmark and reading the *copy* tests messaging differentiation. Removing the copy instead and reading only the *visual system* — color, typography, photography or illustration style, layout rhythm — tests visual differentiation, and a brand can fail one while passing the other. A brand with a distinctive visual system but interchangeable copy has a messaging problem, not a design problem, and vice versa — conflating the two produces a fix (rewrite the site vs. rebuild the visual identity) that solves the wrong half.

## Step 6 — Check the visual system alongside the words

**Check the visual system alongside the words, not just the message.** Half of what a buyer notices switching from an ad to the homepage to a sales deck is color, type, and imagery — a touchpoint can repeat the right message in the wrong visual language and still feel inconsistent. A fast, practical tell: check the sales deck and one-pager's file modification date, not just the filename. A deck last edited well before the homepage's last redesign is carrying the old visual system by default, whatever the filename claims — verify the artifact itself rather than assuming a recent-sounding name means recently updated.
