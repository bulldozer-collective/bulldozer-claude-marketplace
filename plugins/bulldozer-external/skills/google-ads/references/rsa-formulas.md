# RSA Headline and Description Formulas

### 15 Headline Formula

**Primary value proposition (3–4 headlines)**:
- "[Product Name] — [Primary Benefit]"
- "[Outcome] in [Timeframe]"
- "[Number] Users Trust [Product Name]"
- "The [Category] Built for [ICP]"

**Feature/benefit highlights (4–5 headlines)**:
- "No Credit Card Required"
- "Free [X]-Day Trial"
- "[Key Feature] That [Competitors] Don't Have"
- "[Specific number] integrations"
- "[Guarantee or Risk Reducer]"

**CTA headlines (2–3 headlines)**:
- "Start Free Trial Today"
- "Get a Demo in 24 Hours"
- "See [Product] in Action"

**Social proof (2–3 headlines)**:
- "Rated [X]/5 on G2"
- "Trusted by [X]+ Companies"
- "[Specific customer win, e.g., 'Cut reporting time by 60%']"

**Character limit**: Each headline max 30 characters. Each description max 90 characters. Minimum 3 headlines and 2 descriptions to publish, but supply all 15 + 4 — Google needs the full set to test combinations and grade Ad Strength. Bulldozer OS itself enforces this exact contract when writing ad copy back to a live ad group (3–15 headlines / 2–4 descriptions, same character caps) — there is no separate "internal" limit to reconcile with Google's.

**Pushing a copy change back to a live ad group replaces the whole list, not just what changed.** Bulldozer OS's ad-copy update (`bdzUpdateSeaL2`) overwrites the entire headlines list and the entire descriptions list — to test one new headline, resend all 15, not just the new one. Send only one of the two lists and the other's already-stored copy carries over untouched, *except* on a legacy ad group with no stored copy yet, where omitting either one fails outright and both must be sent together.

**Pin headline 1**: Your most important message (brand name + core value prop). Pinning ensures it always appears in position 1 — unless AI Max for Search with Final URL expansion is active on the campaign, in which case Google can still override it (see Keyword Strategy above — since the September 2026 auto-upgrade, that's increasingly the default state rather than a choice the account made). Note also that a pin only reliably guarantees serving for headline 1, headline 2, or description 1 — pinning further down the list (headline 3, description 2–4) doesn't carry the same guarantee.

**Pin sparingly — 2–3 headlines at most**, reserved for what genuinely can't rotate (a legally-required disclaimer, a brand name you're contractually obligated to show). Never pin a headline just because it's been winning — a good headline earns its position by winning the rotation, and pinning it defeats the point of testing 15 combinations in the first place. Over-pinning turns an RSA back into a static ad.

**Ad Strength: aim for "Good," not "Excellent" at any cost.** Chasing "Excellent" usually means padding in a 13th or 14th headline that doesn't add a genuinely different angle — it just dilutes the combination pool. A "Good"-rated ad with 8 sharp, distinct headlines outperforms an "Excellent"-rated one padded with filler more often than the label suggests.

### 4 Description Formula

- **Description 1**: Expand on core value prop + primary CTA
- **Description 2**: Address key objection (price, setup time, switching)
- **Description 3**: Social proof + secondary CTA
- **Description 4**: Feature-specific for high-intent searchers
