### Category Creation (define a new category)

**Best when:**
- The problem exists but buyers don't know there's a product category for it
- You're combining things that haven't been combined before
- The existing categories frame the problem in the wrong way

**Risk**: Category creation is expensive. Buyers need to be educated before they can evaluate you, over a multi-year runway — the exact length isn't reliably sourced, so hold it as "years, not quarters" rather than citing a precise figure. Most teams that reach for this option actually lack the standing content/PR/analyst-relations capacity to sustain it and would win faster by sharpening entry instead — see the four gating questions above before treating this section as the answer.

**Famous examples**: Salesforce ("CRM" didn't exist as a concept), Slack ("team messaging" was new), HubSpot ("inbound marketing" was invented to describe a category).

**Category creation playbook:**
1. Name the category (a new name buyers can latch onto)
2. Describe the enemy (the old way of doing things — not a competitor, a behavior)
3. Define the category criteria so you win by them
4. Invite others to participate (paradoxically, competitor-alternatives validate the category)
5. Own the category narrative through content, events, and research

### Decision Framework

| Question | Entry | Creation |
|----------|-------|----------|
| Buyers already searching for a solution? | Yes | No |
| Established vendors already capture real buyer budget in this market? | Yes | No |
| Your differentiation fits existing evaluation criteria? | Yes | No |
| Part 3 shows most buyers at Solution-aware or further? | Yes | No |
| Positioning already clean — reps repeat it unprompted, site doesn't read as generic? | (fix this first regardless) | Only once true |
| Standing content/PR/analyst-relations capacity for a multi-year push? | Not required | Required |
| You're combining things nobody has combined before? | No | Yes |

A single "Creation" answer isn't a mandate — score the whole row. Most sessions land on Entry once Part 3 and the capacity question are answered honestly; treat a clean sweep of "Creation" answers as rare enough to double-check before committing to it.
