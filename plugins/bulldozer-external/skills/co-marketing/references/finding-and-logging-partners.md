# Finding partners with data tools, and logging them in Bulldozer OS

Referenced from "Where to Find Partners" in the main skill.

**Data tools**: Crossbeam for account overlap — still the category leader for ecosystem-led-growth ("nearbound") tooling as of 2026, and Bulldozer OS has no native equivalent (no cross-company account-matching API), so this step stays manual. Don't treat Crossbeam and Reveal as two separate options to pick between: the two merged in an all-stock deal announced June 2024, Reveal's standalone platform has since been sunset, and the combined company now ships one product under the Crossbeam brand. Customer surveys ("what else do you use?"). G2/Capterra category neighbors — note that Bulldozer OS's own review tool only pulls Trustpilot and Google Business Profile, not G2, so a G2-neighbor check still means a manual look at G2's category page (and treat what you find there as a directory of adjacent tools, not as evidence of what a candidate's customers actually think — G2/Capterra pages run on solicited reviews, not a spontaneous sample).

**Bulldozer OS**: don't log a candidate partner as a competitor, even typed "inspiration" — that field only accepts "competitor" or "inspiration," nothing else, and either choice mixes a partner into the competitive data other skills read (sales-enablement pulls from the same competitor list to write objection-handling copy). Log the partner as a company instead — search for it first (name/website/LinkedIn URL) in case it's already on file from a prior campaign, and create it tagged, e.g. `tags: ["co-marketing-partner"]`, if it isn't. Keep the relationship status in that company's description field, updated after each touchpoint. Before reaching out, pull the partner's real LinkedIn engagement instead of guessing: start a post search job on their profile URL, poll it until it succeeds, then read the results back — ask for a 3-month window on a first check, not a full year, since the job bills per page pulled. Sort or filter that read for the posts that actually landed (by reaction count, or a minimum reactions/comments floor) rather than eyeballing a raw feed — reactions and comments are a better "audience size" signal than follower count alone, and it feeds the Partner Scoring Criteria table above directly. If the partnership moves forward, a monthly refresh on that same profile URL keeps the read current without re-running the one-off job each time.

**Storing the campaign brief itself**: once it's written, store it as a workspace text file rather than a project link — project links are restricted to six strategy/market categories with nothing for partnerships or campaigns, and a workspace file is what the brief actually is (a document to keep, not a URL to bookmark). This write is owner-only: if you're not the workspace owner, hand the finished brief to someone who is rather than letting the call fail silently. A workspace isn't scoped to this project: it's one container per customer, shared across every project that customer runs in Bulldozer OS, and nothing in the chain from project to workspace links the two. Resolve the right workspace by listing the customer's workspaces rather than assuming there's a dedicated one for this project, and tell whoever owns the brief that it will sit alongside files from the customer's other projects — not in a folder isolated to this campaign.
