# Monitoring AI Visibility — Caveats, Search Console Reports, Thresholds and DIY Check

This list moves fast and every source above is a vendor comparing itself to competitors — confirm current pricing and coverage before recommending one, don't quote this table as settled.

**Check Search Console's own AI report before recommending any of the above.** Google announced this report on 2026-06-03 to a subset of properties, widened it on 2026-08-11, then confirmed a worldwide rollout on 2026-08-31 — three separate, named milestones rather than one launch date. Search Console carries a dedicated **Generative AI performance report** — separate from the standard Performance report: impressions of the domain's pages inside Google AI Overviews, AI Mode, and Discover's AI features, broken down by page, country, device and date. No clicks, no CTR, no query-level breakdown — impressions only, and UI-only: the Search Analytics API underneath (the one `bdzGetGscDomainAnalytics` wraps) still only accepts the long-standing `web`/`image`/`video`/`news`/`discover`/`googleNews` search types — nothing generative-AI-specific has been added to it. **Don't assume a client who can't find the report just has an older account that hasn't gotten it yet**: Google's John Mueller has confirmed it still doesn't show on every domain even post-rollout — like the Discover and News reports it mirrors, it only displays once a site has picked up enough impressions inside AI Overviews/AI Mode for Google to bother rendering it. A site with little-to-no AI-surface presence yet simply won't see the report, access or not. For a project with GSC already connected in Bulldozer OS, this is a real, free, first-party signal worth a manual look in the Search Console UI before spending on any tool in the table above — but it's not something Bulldozer OS can pull for you yet; flag it as a gap if this report becomes central to a client's reporting.

**A second free signal, session-level rather than impression-level.** Starting 2026-05-13, Google began rolling out a native "AI Assistant" channel in the GA4 Default Channel Group — it auto-classifies referrals from ChatGPT, Gemini, Copilot, DeepSeek and Grok by reading the referrer header, no configuration needed. It has real gaps worth knowing before trusting the number: Perplexity isn't in the native channel and still lands in plain Referral, the rollout isn't retroactive, and a large share of AI-assistant sessions arrive with no referrer at all and fall into Direct (several trackers put this at 35-65%, varying by platform) — so this channel undercounts, it never overcounts. A separate, later Google rollout narrows the Perplexity gap: a new **Source Group** dimension, announced 2026-06-11, groups messy source strings into one canonical value per platform and explicitly covers ChatGPT and Perplexity, applied retroactively to historical data — check this dimension alongside the AI Assistant channel rather than only building a manual grouping for Perplexity from scratch. Reported consistently across several analytics/SEO outlets; we couldn't load an official Google page to confirm either mechanism directly (`support.google.com` blocked in this environment), so treat both as real and the coverage numbers as approximate. For a project with GA4 already connected in Bulldozer OS, `bdzApplyGoogleAnalyticsTemplatePreset` (`presetId: channel_attribution`) is the fastest way to see the channel breakdown without building a report by hand; pair it with a manually-defined custom channel group (source containing `chatgpt`, `perplexity`, `gemini`, `openai`, `copilot`) to catch whatever the native channel, Source Group and Direct still miss.

**The threshold that matters**: don't move a client to a paid monitoring tool (table above) on the strength of "AI search matters now." Move when these two free views — undercounting as they are — already show AI-referred visibility as a real, growing line, not a rounding error next to organic and paid. Below that, the DIY check below is enough.

**DIY monthly check**: Pick 20 priority queries, run through ChatGPT, Perplexity, Google. Record: cited? Who? Which page? Track month-over-month in a spreadsheet.
