# Scoring Rubric — Quick Reference

A compact reference for the 1-10 scale and the eight dimensions. The main skill file
carries the score-band table (9-10 / 5-6 / 1-2) used while scoring; this file is the
fuller version to open when a score needs to be justified against the whole 1-10 scale,
not just the three anchor bands.

## 1. The 1-10 scale

| Score | Label | Meaning |
|---|---|---|
| 10 | Exceptional | Best-in-class, award-worthy or viral-level |
| 9 | Excellent | Polished, professional, highly effective |
| 8 | Very Good | Strong, minor room for improvement |
| 7 | Good | Solid, above average for its category |
| 6 | Above Average | Competent but not distinctive — does the job |
| 5 | Average | Neither good nor bad |
| 4 | Below Average | Noticeable issues that reduce effectiveness |
| 3 | Poor | Significant problems, likely to underperform |
| 2 | Very Poor | Fundamental flaws — should not be published |
| 1 | Terrible | Actively damages the brand |

## 2. Dimensions at a glance

| # | Dimension | Weight | Guiding question |
|---|---|---|---|
| 1 | Hook Effectiveness | 1.5x | Does the first 3 seconds stop the scroll? |
| 2 | Message Clarity | 1.3x | Can the viewer state the value proposition? |
| 3 | Visual Quality | 1.0x | Does it suit the platform? |
| 4 | Audience Targeting | 1.2x | Does a specific audience feel it's meant for them? |
| 5 | Pacing & Structure | 1.0x | Does each second earn the next? |
| 6 | CTA Strength | 1.3x | Does it drive action? |
| 7 | Emotional Resonance | 1.0x | Does it make the viewer feel something? |
| 8 | Sound-Off Effectiveness | 0.7x | Does it work without audio? |

Hook carries the most weight (1.5x), followed by Message Clarity and CTA Strength (1.3x
each), then Audience Targeting (1.2x). Sound-Off carries the least (0.7x) — a real but
secondary consideration next to whether the ad works at all.

## 3. Overall score formula

```
Overall = (Hook×1.5 + Message×1.3 + Visual×1.0 + Audience×1.2 + Pacing×1.0
           + CTA×1.3 + Emotion×1.0 + SoundOff×0.7) / 9.0
```

## 4. Quick decision guide

| Overall score | Decision |
|---|---|
| 8.5+ | Ship immediately and scale budget |
| 7.0–8.4 | Ship with minor fixes |
| 5.5–6.9 | Fix the top two weakest dimensions first |
| 4.0–5.4 | Major rework needed |
| Below 4.0 | Start over with a new concept |
