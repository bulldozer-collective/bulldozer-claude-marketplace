# Platform Image Sizes

Organic-content sizes — blog, OG/social preview, and native posts/covers on each network.
For paid-ad placements (Meta, TikTok, LinkedIn, Pinterest, YouTube, programmatic display),
see *ad-creative-brief* instead — a different matrix, by placement rather than by network,
and it changes on its own schedule.

| Platform | Recommended size | Notes |
|----------|-----------------|-------|
| Blog hero | 1200×630px | Also works as OG image |
| OG image (social preview) | 1200×630px | 1.91:1 aspect ratio; keep headline and faces inside the center ~1080×600 safe zone, file under 1MB |
| LinkedIn post image | 1200×627px | Near identical to OG |
| Twitter/X header | 1500×500px | 3:1; leave the bottom-left clear for the profile photo, ~60px top/bottom get cropped on some screens |
| Instagram feed, portrait (default) | 1080×1350px | 4:5 — this is the platform default today, not square |
| Instagram feed, square | 1080×1080px | Still accepted, no longer the default |
| Instagram story/reel | 1080×1920px | |
| Facebook cover | 820×312px | Desktop; crops to ~640×360 on mobile — keep key elements centered |
| LinkedIn personal profile cover | 1584×396px | Personal profile background photo, not the company Page banner |
| LinkedIn company Page banner | Upload 4200×700px (6:1) | Different asset from the personal cover above; LinkedIn renders it down to ~1128×191px, and the company logo overlaps the bottom-left corner at that render size — keep it clear |
| Meta feed image | 1080×1080px (square) or 1080×1350px (portrait) | |
